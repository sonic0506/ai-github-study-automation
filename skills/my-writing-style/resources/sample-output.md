# 목표 문체 예시

아래는 위 규칙을 적용했을 때 나와야 하는 형태다. **내용은 예시일 뿐이므로 사실로 인용하지 않는다.**

---

## 01. 어떤 문제를 푸는가

에이전트에 외부 도구를 붙일 때마다 연결 코드를 새로 작성하게 됩니다.
이 저장소는 그 연결 부분을 서버 하나로 표준화해서, 도구를 추가할 때 서버 설정만 바꾸면 되도록 합니다.

- 해결 대상 : 에이전트마다 도구 연동 코드를 중복 작성하는 문제
- 접근 : 도구 호출 규약을 JSON-RPC 기반으로 고정하고 서버가 중계함
- 범위 : 도구 실행까지. 모델 호출이나 프롬프트 관리는 포함하지 않음

## 02. 핵심 구조

구성 요소는 세 가지입니다. 클라이언트가 서버에 도구 목록을 요청하고, 서버가 실제 실행을 담당합니다.

- 클라이언트 : 에이전트 쪽에 붙어 도구 목록과 실행 결과를 주고받음
- 서버 : 도구를 등록하고 실행 결과를 반환함
- 전송 계층 : stdio와 HTTP 두 가지를 지원함

## 03. 시작하기

설치 후 서버를 띄우고 클라이언트에서 연결하면 됩니다.

```bash
npm install example-mcp
npx example-mcp serve --port 3000
```

```ts
// 서버에 도구를 등록하는 부분
server.tool('search', { query: z.string() }, async ({ query }) => {
  return await search(query); // 실행 결과를 그대로 반환
});
```

(포트를 바꾸면 클라이언트 설정 파일의 주소도 함께 고쳐야 합니다.)
