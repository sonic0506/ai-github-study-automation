# Examples

사용자가 직접 쓴 글. 문체 판단의 기준 자료다.

| 파일 | 유형 | 특징 |
|---|---|---|
| `study-01.md` ~ `study-03.md` | 스터디 정리 | 번호 섹션, 대시 불릿, `용어 : 설명` 정의, 개조식(`~함`/`~음`), 코드에 한국어 주석 |
| `casual-01.md` ~ `casual-03.md` | 블로그 포스팅 | 합니다체 설명, 단계 순서 안내, 단축키 표기, 괄호 주의사항 |

Study 문서는 **스터디 글의 구조 + 블로그 글의 설명 어조**를 섞어 쓴다.
블로그 글의 인사말·이모티콘·근황 이야기는 가져오지 않는다 (`anti-patterns.md`).

글을 추가할 때는 `study-` 또는 `casual-` 접두사를 붙인다.
