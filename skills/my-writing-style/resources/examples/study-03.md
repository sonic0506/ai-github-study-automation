01. Custom Hook 필요성

- 반복되는 코드들을 따로 분리하여 Hook으로 만들면 긴 코드를 계속해서 작성할 필요가 없어지기 때문에 효율이 증가함

- input, 비동기 통신 등을 커스텀 훅으로 작성

02. 기능분리하기

- 기존 컴포넌트에서 사용했던 비동기 통신을 위한 상태들과 메서드를 분리하여 새로운 파일을 만듦

- 첫번째 인자로는 비동기 통신을 수행하는 콜백함수를 받고, 두번째 인자로는 의존하는 대상(그 대상이 변경되면 비동기 통신을 다시 수행함)이 있다면 배열에 담아서 받음

- 상태관리

    - loading : 로딩 상태

    - data : 통신으로 전달 받은 데이터

    - error : 통신중 발생한 에러
