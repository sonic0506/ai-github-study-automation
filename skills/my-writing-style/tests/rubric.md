# my-writing-style 평가 Rubric

- [ ] ★ 입력 Research Note의 숫자·버전·URL·`sources`·`studyability`가 모두 동일하다 (기계 비교).
- [ ] ★ 입력에 없는 사실이 추가되지 않았다.
- [ ] ★ `anti-patterns.md`의 표현이 0건이다 (인사말·맺음말·이모티콘·과장 표현).
- [ ] ★ 설명 문단은 합니다체, 정리·목록은 개조식이다. 한 문단 안에서 섞이지 않았다.
- [ ] 정의가 `- 용어 : 설명` 형태로 되어 있다.
- [ ] 한 문단이 3문장 이하, 한 문장이 80자 이하다.
- [ ] 영문 기술 용어가 원문 그대로 유지되었다 (MCP, RAG, LLM 등).
- [ ] 추측성 내용에 `~라고 합니다` / `~로 보입니다`가 붙어 있다.
- [ ] `resources/sample-output.md`와 나란히 읽었을 때 같은 문체로 읽힌다.
